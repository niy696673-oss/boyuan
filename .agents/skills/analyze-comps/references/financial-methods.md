# Comparable-analysis financial methods

## Value definitions

```text
EquityValue = DilutedShares × SharePrice
EnterpriseValue = EquityValue + Debt + Preferred + NCI + OtherClaims + ApplicableLeaseClaims - Cash - NonOperatingInvestments
P/E = CommonEquityValue / NetIncomeAvailableToCommon
P/S = EquityValue / Revenue
EV/Revenue = EnterpriseValue / Revenue
EV/EBITDA = EnterpriseValue / EBITDA
```

Adapt the bridge to the transaction and disclose every included item. Include lease claims
only when consistent with the operating metric and selected market convention; do not add a
lease liability already captured in the denominator or reported enterprise value. Reconcile
options, warrants, convertibles, preferred securities, employee pools, and other contingent
shares to a dated fully diluted share count. Use treasury-stock treatment only where
appropriate and disclose assumed exercise proceeds. Keep NCI in the enterprise bridge when
the denominator includes consolidated operations attributable to NCI.

## Denominators

Align LTM, NTM, fiscal-year, run-rate, reported, adjusted, and recurring definitions.
Do not calculate a multiple on a denominator with a different entity perimeter.

Use `NM` for negative, zero, or economically meaningless denominators. Do not let extreme
values distort means or charts.

## Statistics

Show count, minimum, lower quartile, median, upper quartile, and maximum when the sample
supports them. Use mean only with an explanation. Never delete an outlier solely because
it is more than a fixed number of standard deviations away.

## Implied value

Apply an approved peer statistic to the matching target metric. For enterprise multiples,
bridge implied enterprise value to common equity. For equity multiples, apply the correct
equity denominator and fully diluted share count.

## Mode-specific controls

- Public comps: current security/market values and aligned forecast periods.
- Precedents: transaction value, control, synergies, status, and target financial period.
- Private rounds: pre/post-money, primary/secondary, security rights, stage, date, and dilution.
