# Three-statement workflow

## Intake and mapping

Confirm entity perimeter, accounting basis, currency, units, fiscal calendar, historical
and forecast periods, source files, management adjustments, model purpose, and template
policy. Inventory workbook sheets, named ranges, hidden content, formulas, checks, and links.

## Controlled sequence

1. Map source labels to canonical line items without losing source terminology.
2. Reconcile historical statements and document reclassifications.
3. Obtain scope approval before editing or building projections.
4. Build supporting schedules before statements.
5. Project the income statement from approved drivers.
6. Project the balance sheet from roll-forwards.
7. Project cash flow and reconcile ending cash.
8. Implement circularity policy and scenarios.
9. Run all checks and inspect liquidity.
10. Deliver only after formula recalculation or mark recalculation required.

## Stop conditions

Return a readiness report when opening balances, entity scope, periods, units, or material
accounting policies cannot be reconciled. Never add a balancing plug to hide the issue.

## Source-file rule

Work on a copy when permitted. Do not overwrite originals, remove formulas, flatten
workbooks, delete hidden sheets, or change a template structure without approval.

## Handoff

Provide DCF/LBO workflows with approved forecast periods, UFCF components, evidence and
assumption registers, scenario identifiers, liquidity status, and tie-out results.
