# Document taxonomy

先提取所有类型共用字段：标题、日期/期间、主体、版本、语言、资料状态、关键实体、关键事实、标签、缺失信息和来源定位。允许一份资料有一个主类型和多个辅助标签；不能可靠分类时使用 `general_attachment` 并说明原因。

| 资料类型 | 包含 | 最低提取字段 | 类型特有风险检查 |
| --- | --- | --- | --- |
| `bp_cim_teaser` | BP、商业计划书、CIM、teaser、路演材料 | 公司与一句话介绍、行业、产品、商业模式、客户、市场、竞争、团队、经营数据、融资信息、资金用途 | 市场口径混用、预测当事实、客户/订单未验证、融资前后估值混淆 |
| `financial_model` | 三张表、预算、预测、估值、cap table、经营模型 | 工作表清单、币种/单位、期间、历史与预测边界、收入/成本/现金、关键假设、公式或外链异常 | 公式错误、硬编码、循环引用、单位/币种不一致、隐藏行列、情景假设缺失 |
| `industry_research` | 行业报告、券商/咨询研究、市场数据 | 发布方、发布日期、研究范围、样本/方法、市场规模、增速、竞争格局、关键结论 | 来源陈旧、二手引用、样本偏差、定义口径不一致、付费版权限制 |
| `due_diligence` | 尽调清单、访谈、数据室材料、红旗报告 | 尽调领域、覆盖范围、已验证事项、例外、待补材料、责任人与日期 | 未闭环例外、证据链断裂、管理层陈述未验证、跨版本冲突 |
| `meeting_record` | 会议纪要、访谈、音视频、逐字稿 | 时间、会议主题、参会角色、议题、决定、行动项、负责人/截止日、时间码或段落定位 | 说话人不明、自动转写错误、意见被误写为决定、行动项无负责人 |
| `legal_transaction` | NDA、SPA、SHA、TS、章程、合同、交易文件 | 当事方、文件类型、版本/日期、标的、金额、期限、条件、义务、终止、争议解决 | 未签署、版本过期、条件未满足、关键责任/赔偿、管辖地、附件缺失 |
| `portfolio_report` | 投后月报/季报、董事会材料、经营复盘 | 报告期、KPI、预算差异、现金/跑道、重大事项、风险、下期计划 | KPI 口径变化、预算基线变化、异常未解释、滞后或选择性披露 |
| `fund_lp` | 基金材料、LP 报告、资本调用、分配、估值材料 | 基金/载体、报告期、承诺/实缴/调用/分配、NAV、费用、投资组合、IRR/MOIC 口径 | 净额/毛额混淆、估值日期不一致、费用遗漏、敏感 LP 信息 |
| `government` | 政策、申报、批复、补贴、监管材料 | 发布/受理机构、文号、日期、适用主体、要求、期限、金额、状态 | 政策过期、适用范围误判、申报期限、附带条件、正式性不明 |
| `email_web` | 邮件、网页、消息导出、链接 | 发件/发布主体、时间、主题/标题、URL、正文摘要、附件/引用链 | 身份或网页真实性、内容可变、截断上下文、个人信息、链接失效 |
| `general_attachment` | 图片、清单、数据导出及其他附件 | 文件用途、核心内容、相关主体/期间、可识别字段、建议标签 | 上下文不足、OCR 错误、格式损坏、敏感信息、无法确认的项目归属 |

## 分类完成条件

- 每个文件有主类型、置信说明和最低字段覆盖情况。
- 缺失字段进入 `missing_information`，不以推断补齐。
- 所有风险均对应文件和来源定位；仅由常识触发的风险写为待验证问题。
