# Detailed Workflow

## 1. Intake and Extraction

Record file name, type, version, date, author, language, and access class. Extract
text, tables, notes, and chart labels. If OCR or native parsing is unavailable,
request pasted content or return a review plan; do not pretend to have read the
file.

Define the review lens before scoring:

- transaction side and current financing stage;
- expected next process gate;
- target investor type and relevant sector mandate;
- named artifact objective and permitted disclosures;
- user-supplied scoring framework, if any.

## 2. Fact Ledger

Create one row for each material claim. Include claim text, normalized value,
unit, period, source ID, exact location, evidence state, and conflict ID. Keep
management claims as claims until corroborated.

Test common cross-document ties:

- revenue, gross margin, cash, headcount, capacity, and customer count;
- round size, valuation basis, capitalization, proceeds, and runway;
- product maturity, certification, production status, and delivery dates;
- market size definitions, peer sets, and stated competitive position.

## 3. Diagnostic Lenses

Apply the following sequence so presentation quality does not mask weak evidence:

1. `source_integrity`: authority, recency, traceability, conflict.
2. `business_substance`: problem, solution, moat, market, commercialization,
   operating model, team, economics, financing need, and risks.
3. `narrative_logic`: claim-to-proof sequence, stage fit, audience fit, and clear
   investment-use relevance.
4. `process_readiness`: availability of supporting material for screening,
   initiation, DD, term negotiation, and approval.
5. `presentation`: information density, visual hierarchy, legibility, and repeated
   or missing messages.

## 4. Objection Hypotheses

Phrase objections as testable hypotheses, not investor facts. For each hypothesis,
state the likely audience, triggering claim, missing proof, disconfirming evidence,
and recommended preparation owner.

## 5. Remediation

Order actions by: evidence-critical before editorial; financing-gating before
cosmetic; current-stage before future-stage. Identify dependencies and owners.
Propose but do not perform downstream rewrites or artifact builds.

## 6. Review

Run a numeric consistency pass, evidence-state pass, audience-fit pass, and
confidentiality pass. Ask the owner to validate severity labels and any internal
house criteria before treating the result as final.
