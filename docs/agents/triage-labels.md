# Triage Labels

Matt Pocock skills 使用五类固定角色。处理 Issue 时使用以下 GitHub 标签：

| Skill 角色        | GitHub 标签       | 含义                           |
| ----------------- | ----------------- | ------------------------------ |
| `needs-triage`    | `needs-triage`    | 等待维护者评估                 |
| `needs-info`      | `needs-info`      | 等待报告者补充信息             |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交给 AI agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工处理                   |
| `wontfix`         | `wontfix`         | 已决定不处理                   |

Skill 提到某个 triage 角色时，使用本表对应的 GitHub 标签。
