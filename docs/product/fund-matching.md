# 快速卡基金匹配

## 数据来源

首版使用用户提供的 `模拟私募基金清单_4只_成都.xlsx`。数据基准日为 `2026-08-28`，金额单位为万元，全部数据均为虚构模拟数据。迁移 19 将四只基金画像写入 SQLite `fund_profiles`，并保留来源文件、基准日和模拟标记。

## 链路

1. Luna 从 BP 或公司快速研究上下文提取行业标签、融资阶段、融资金额和公司区域。
2. 平台从 SQLite 读取基金画像，先排除不在投资期或无可投资金的基金。
3. 本地规则分别计算投资领域 40 分、投资阶段 20 分、单笔金额 20 分、投资区域 10 分和资金能力 10 分。
4. API 返回推荐基金、最多两只备选、逐维得分、可匹配与排除数量、清单来源和基准日。
5. BotMux 将结果写入同一张飞书快速卡；工作台深度研究继续独立运行。

## 语义边界

- 基金匹配度是偏好契合分，不是材料分析置信度，也不是投资决策。
- Luna 只提取项目输入，不得输出基金名称或匹配分数。
- F01 因已不在投资期且无可投资金而被硬性排除；F02–F04 参与评分。
- 缺失融资金额时，金额与资金能力只给中性分并明确提示缺失；所有匹配输入均缺失时不生成匹配度。
- 快速链路不创建公司、行业、关系或正式知识。
